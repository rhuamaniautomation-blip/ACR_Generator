# Plataforma Inteligente de Gestión de ACR, AFA y Confiabilidad Industrial

Sistema integral desarrollado en Python 3.12 y Streamlit para la gestión de Análisis de Causa Raíz (ACR), Análisis de Fallas (FMEA/AFA), 5 Porqués, Diagramas de Ishikawa, Planes de Acción y KPIs de Confiabilidad.

## Características
- IA Industrial (Gemini 2.5, GPT-5 Azure)
- Base de Datos SQLite con autenticación y roles
- Exportación a PDF, Word y Excel
- Listos para Streamlit Cloud
